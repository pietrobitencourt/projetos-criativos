## Estrutura do repositório

```
coracao_love/
├── index.html        # página inicial com a lista de projetos
├── README.md         # este arquivo
└── coracao/          # um projeto por pasta
    ├── index.html
    ├── README.md
    ├── css/
    ├── js/
    ├── python/
    └── img/
```

Cada projeto fica na sua própria pasta, com `index.html` e `README.md` próprios. Assim cada um ganha o seu endereço: `.../coracao_love/NOME-DA-PASTA/`.

## Como rodar um projeto

- **No computador:** abra a pasta do projeto e dê dois cliques no `index.html`.
- **Online:** use o link da coluna *Demonstração* da tabela acima.

## Como adicionar um novo projeto

1. Crie uma pasta com o nome do projeto, em minúsculas e sem espaços (por exemplo, `relogio`).
2. Coloque dentro dela um `index.html`, as pastas `css/` e `js/` e um `README.md`.
3. Adicione uma imagem ou GIF de prévia em `img/`.
4. Inclua o projeto na tabela deste README e na página inicial (`index.html` da raiz).

## Como publicar (GitHub Pages)

1. Vá em **Settings → Pages**.
2. Em *Build and deployment*, escolha **Deploy from a branch**, branch **main** e pasta **/ (root)**, e clique em **Save**.
3. Em 1 ou 2 minutos o site fica no ar em `https://pietrobitencourt.github.io/coracao_love/`.
